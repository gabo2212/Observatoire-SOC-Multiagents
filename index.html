Pipeline

Agents

Six rôles se passent le relais. Les outils font le travail déterministe. Le LLM local synthétise et décide.

01

Coordonnateur

Décompose la mission et orchestre le flux.

02

Collecteur

Charge alertes et inventaire via les outils.

03

Classificateur

Type, gravité, faux positifs.

04

Corrélateur

Campagnes et chaînes d’attaque.

05

Évaluateur

Score de risque et vérification.

06

Rapporteur

Brief final P1, P2, P3.

Exécution

Local

Python 3.12, llama-server et un GGUF d’environ 12 Go. Un GPU NVIDIA est recommandé. Le dashboard ne tourne pas sur Vercel.

01

Installer les dépendances

uv pip install -r requirements.txt

02

Démarrer le LLM local

bash scripts/start_llm.sh

03

Collecter des traces

python -m scripts.run_batch --per-scenario 4 --live 1

04

Ouvrir le dashboard

streamlit run dashboard/app.py
